Данный проект - программы на C++, принимающие значения для вычисления параметров трёх фигур:
1. Окружность
2. Треугольник
3. Трапеция

Участники проекта:
Стуканов В.И. - написание кода для программы, высчитывающей параметры окружности
Лухнёв С.А. - написание кода для программы, высчитывающей параметры трапеции
Идимешев Р.Ю. - написание кода для программы, высчитывающей параметры треугольника; создание репозитория
